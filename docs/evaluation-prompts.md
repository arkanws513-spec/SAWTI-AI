# Arabic evaluation prompts

This is a small, original, manually curated starter set for repeatable listening tests. It is not a benchmark and does not establish model quality.

## How to use it
1. Record the prompts using your own voice in a quiet place.
2. Keep each prompt as a separate WAV file and preserve the exact text in the CSV.
3. Compare candidate systems using the same prompts and similar playback volume.
4. Rate pronunciation, missing/added words, naturalness, pacing, and dialect fidelity separately.
5. Keep these prompts as a held-out evaluation set; do not train on them if you want a fair comparison.

The set includes Egyptian colloquial Arabic (ar-EG) and Modern Standard Arabic (ar), with conversational questions, numbers, and longer reading sentences. Add more examples only when a clear coverage gap appears.

## Privacy
These prompts contain no personal information. Your recordings do. Keep audio private, and use only your own voice or recordings with explicit permission for the intended use.
